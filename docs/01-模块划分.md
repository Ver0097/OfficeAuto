# OA管理系统 - 模块划分设计

│   │   │   ├── user/                 # 用户管理
│   │   │   ├── role/                 # 角色管理
│   │   │   ├── menu/                 # 菜单管理

│   │   │   └── permission/           # 权限管理
│   │   │
│   │   ├── approval/                 # 审批流程模块
│   │   │   ├── leave/                # 请假审批
│   │   │   ├── expense/              # 报销审批

│   │   │

│   │       └── handler/              # 认证处理器

│
├── frontend/                         # 前端模块
│   ├── src/
│   │   ├── api/                      # API接口

│

## 2. 模块职责划分

### 2.1 公共模块 (common)

| 子模块 | 职责 |
|--------|------|
| config | 全局配置（Cors、MyBatis、Swagger等） |
| exception | 全局异常处理器、自定义业务异常 |
| utils | 通用工具（日期、字符串、加密等） |
| result | 统一响应格式 Result<T> |

### 2.2 系统管理模块 (system)

| 子模块 | 职责 | 核心功能 |
|--------|------|----------|
| user | 用户管理 | CRUD、状态切换、密码重置 |
| role | 角色管理 | CRUD、分配菜单权限 |
| menu | 菜单管理 | CRUD、树形结构、路由元数据 |
| dept | 部门管理 | CRUD、树形结构 |
| permission | 权限管理 | 按钮级权限标识 |

### 2.3 审批流程模块 (approval)

| 子模块 | 职责 | 核心功能 |
|--------|------|----------|
| leave | 请假审批 | 申请提交、审批操作、记录查询 |
| expense | 报销审批 | 申请提交、审批操作、记录查询 |
| flow | 流程定义 | 审批节点配置、流程模板 |

### 2.4 安全认证模块 (security)

| 子模块 | 职责 |
|--------|------|
| jwt | JWT令牌生成、解析、验证 |
| filter | 认证过滤器、权限拦截 |
| handler | 登录成功/失败处理、登出处理 |

## 3. 技术分层

```
┌─────────────────────────────────────────┐
│           Controller 层                   │  接口定义、参数校验
├─────────────────────────────────────────┤
│           Service 层                      │  业务逻辑、事务控制
├─────────────────────────────────────────┤

├─────────────────────────────────────────┤
│           数据库 (MySQL)                   │  数据存储
└─────────────────────────────────────────┘
```

## 4. 模块依赖关系

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   approval   │────▶│   system     │────▶│   security   │
└──────────────┘     └──────────────┘     └──────────────┘
        │                   │                    │
        └                   └                   │
        └───────────────────┴───────────────────▼
                        ┌──────────────┐
                        │    common    │
                        └──────────────┘
```

- **approval** 依赖 **system**：审批需要用户、部门信息
- **system** 依赖 **security**：用户管理需要认证鉴权
- **所有模块** 依赖 **common**：公共组件
